# ReplayClipTrainer

**日本語** | [English](README.en.md)

ReplayClipTrainer は、Rocket League のリプレイを「操作できる練習用プライベートマッチ」に変換する BakkesMod プラグインです。リプレイの好きな瞬間から、好きな選手（味方でも相手でも）の操作を奪って、同じシーンを何度も練習できます。

エアリアル練習、ドリブル練習、特定の場面での判断練習など、実際に起きたプレーをそのまま反復練習したい場合に使えます。

本プラグインは [JumpInReplay](https://github.com/Atomus48/JumpInReplay)（作者: Atomus48）をベースにしたフォークで、クリップ変換・保存管理・設定GUIなどを大きく拡張したものです。

## インストール方法

> **ソースからのビルドを推奨します。** Releases に配布用の `.dll` も置いていますが、未署名の DLL はセキュリティソフトに検出・隔離されることがあります。ソースからビルドすれば、中身を自分で確認でき、手元の BakkesMod に合わせたDLLができます。手順は[ビルド方法](#ビルド方法)を参照してください。

### ビルド済みの DLL を使う場合

1. リポジトリの Releases から `.dll` ファイルを取得します。
2. `.dll` ファイルを BakkesMod のプラグインフォルダにコピーします。
   - `%APPDATA%\bakkesmod\bakkesmod\plugins`
3. 起動時に自動読み込みさせたい場合は、`cfg\plugins.cfg` の末尾に以下を追記します。
   ```
   plugin load replaycliptrainer
   ```
4. Rocket League を起動すれば使用できます。

## ビルド方法

### 必要なもの

- Windows 10 / 11（x64）
- [Visual Studio 2022](https://visualstudio.microsoft.com/ja/downloads/)（Community で可）。インストール時に「**C++ によるデスクトップ開発**」ワークロードを選択してください（MSVC v143 と Windows SDK が含まれます）。
- [BakkesMod](https://bakkesmod.com/)（インストール済みであること）。プラグイン開発用の SDK（`bakkesmodsdk`）が一緒にインストールされ、ビルドはそれを使います。
- Git（ソースの取得用。zip をダウンロードする場合は不要）

### 手順

1. ソースを取得します。
   ```powershell
   git clone https://github.com/ya-games/ReplayClipTrainer.git
   cd ReplayClipTrainer
   ```
2. ビルドします（どちらか一方）。
   - **Visual Studio から**: `ReplayClipTrainer\ReplayClipTrainer.sln` を開き、構成を「**Release**」・プラットフォームを「**x64**」にして「ビルド → ソリューションのビルド」。
   - **コマンドラインから**（PowerShell。Bash では `/p:` の引数が壊れることがあります）:
     ```powershell
     & "C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe" `
       "ReplayClipTrainer\ReplayClipTrainer.sln" `
       /p:Configuration=Release /p:Platform=x64 `
       /p:BakkesModPath="$env:APPDATA\bakkesmod\bakkesmod" /nologo /v:minimal
     ```
     Visual Studio を別のエディション・場所に入れている場合は、`MSBuild.exe` のパスを読み替えてください。
3. ビルド後の処理で、BakkesMod 付属の `bakkesmod-patch.exe` が DLL を処理し、BakkesMod の `plugins` フォルダへ自動でコピーされます（ゲーム起動中ならそのまま再読み込みされます）。ビルドした DLL 自体は `ReplayClipTrainer\plugins\ReplayClipTrainer.dll` にも残ります。
4. 初回のみ、`cfg\plugins.cfg` に `plugin load replaycliptrainer` を追記するか、BakkesMod のコンソール（F6）で `plugin load replaycliptrainer` を実行します。

### 補足・トラブルシューティング

- **BakkesMod の場所**: 通常はレジストリ（`HKCU\Software\BakkesMod\AppPath`）から自動で見つかります。見つからない・別の場所にある場合は、`/p:BakkesModPath="<BakkesModのフォルダ>"` で指定してください（`bakkesmodsdk` フォルダがある階層です）。
- **ファイルが使用中というエラーで失敗する**: Rocket League / BakkesMod が DLL を開いたままです。ゲームを終了して、もう一度ビルドしてください。
- **セキュリティソフトに DLL を隔離された**: 自分でビルドした DLL でも、未署名のためまれに検出されることがあります。ソースは公開されているので、内容を確認した上で、BakkesMod のフォルダを除外設定に追加してください。
- バージョンは `ReplayClipTrainer\version.h` で管理しています（`MAJOR.MINOR.PATCH`）。

## 使い方

BakkesMod の F2メニュー → Plugins → ReplayClipTrainer、またはコンソールで `togglemenu ReplayClipTrainer`（または `reclip_window`）を実行すると、設定画面の表示／非表示を切り替えられます。基本的な操作はすべてこの画面から行います。

大まかな流れ：

1. 練習したいリプレイを再生する
2. リプレイをスクラブして、練習したい瞬間まで移動する
3. 「あとで練習(保存)」でクリップをファイルに保存する（主な使い方）。保存せずその場で練習したいときは「今すぐ練習」
4. 保存したクリップを「クリップ」タブから読み込むと、プライベートマッチでクリップが自動再生される
5. 好きなタイミングで「自分で操作」して、その選手の操作を奪う

## 主な機能

設定画面は「変換 / クリップ / 設定」の3タブ構成です。

### 変換タブ：クリップの変換・保存

- **リプレイの位置**（リプレイ再生中のみ）: 現在の再生位置をバーで表示し、クリック/ドラッグで好きな位置へ一発でジャンプできます。ゴール（得点したチームの色の丸）とハイライト（灰色の菱形）の位置が表示され、マウスを乗せると内容と時刻が分かります。
- **切り出し範囲**:
  - 「スクラブ位置の何秒前から」「スクラブ位置の何秒後まで」: 現在のスクラブ位置の前後何秒を切り出すかを指定します。前後の合計が5秒未満の場合は変換できません。
  - 「変換の細かさ(解像度)」: クリップ変換時に、元のリプレイを何倍速で読み込みながら記録するかの値です（0.1〜2.0、既定値0.5）。
    - `1.0` が等倍速。
    - `1.0`より小さい値（例: `0.5`）にすると、リプレイをゆっくり再生しながら記録するため、記録のデータ密度が上がり、変換後の動きがより滑らかになります。ただし変換にかかる時間は長くなります。
    - `1.0`より大きい値（例: `2.0`）にすると、リプレイを早送りしながら記録するため変換は速く終わりますが、動きがやや粗く（カクつき気味に）なります。
- **クリップを保存**: クリップ名を入力（空欄なら自動命名）して「あとで練習(保存)」を押すと、プライベートマッチを開かずにクリップをファイル（`.reclip`）として保存します。1本のリプレイから複数のシーンを保存し、後でまとめて練習できます。
  - 「保存時に選手名を匿名化」をオンにすると、選手名を `Player1, 2, 3…` に置き換えて保存します。保存時に観戦していた選手が Player1、次に味方、最後に相手の順です（1v1〜3v3 対応）。クリップを共有するときに便利です。
- **保存せずにすぐ練習**: 「今すぐ練習」は、切り出した範囲を保存せずに、すぐプライベートマッチとして練習を始める補助機能です。
- 変換中は、進行バー（画面上部）が表示されます。リプレイが一時停止していると変換が進まないため、その旨が表示されます。「キャンセル」で中断もできます。

### クリップタブ：保存済みクリップの管理

- 保存済みクリップは一覧表示され、保存日時やプレイヤー人数が確認できます。
- **フォルダで整理**できます。「新しいフォルダ」で作成、フォルダ行の「…」で名前の変更・削除（空のフォルダのみ）。「フォルダを開く」で、今見ているフォルダをエクスプローラーで開けます。
- クリップ行の「…」で、**名前の変更**と**別のフォルダへの移動**ができます。
- 「読み込み」でクリップを開き、「削除」はミスを防ぐため押すと「削除する / キャンセル」に切り替わる2段階確認です。
- 「更新」で一覧を更新、「直前のクリップをやり直す」で直前に変換/読み込んだクリップをもう一度開けます。
- 「最近のクリップのみ」にすると、フォルダの階層に関係なく、直近（1〜48時間から選択、既定12時間）に保存したクリップを新しい順にまとめて表示します。
- 古いバージョンで保存された互換性のないクリップは一覧でグレーアウトされ、誤って読み込まないようになっています。

### 練習中の操作

- クリップは自動で再生されます。画面上には現在の状態が「**自動再生中**」「**操作中**」と表示され、その下に、キーを押すと何が起きるか（「押すと『自分で操作』」など）が表示されます。
- 「自分で操作」で、再生中の選手の操作を奪って自分でプレーできます。クリップを開いた直後は、元のリプレイであなたが実際に観戦していた選手が自動的に選ばれます。「自動再生に戻す」で元の再生に戻ります。
- 一時停止・巻き戻し/早送り、選手の切り替えができます。
- 画面の左上に、キー操作の説明を小さく表示できます（設定タブでオン/オフ）。

#### キー割り当て

設定タブの「標準の割り当てを適用」ボタンを押すと、以下のキー/コントローラー割り当てが適用されます（初回に一度押せば、BakkesMod側に保存されるので次回起動時も押し直す必要はありません）。

| 操作 | キーボード | コントローラー |
| --- | --- | --- |
| 5秒早送り | → | DPad右 |
| 5秒巻き戻し | ← | DPad左 |
| 次の選手 | ↑ | DPad上 |
| 前の選手 | ↓ | DPad下 |
| 一時停止/再開 | B | 左スティック押し込み |
| 自分で操作 / 自動再生に戻す | V | Back/Selectボタン |

キー自体を変更したい場合は、BakkesMod本体の「Bindings」タブから個別に変更できます。

### 設定タブ

- **ブーストを制限する**: 練習中のブーストを制限あり/無制限のどちらにするかです。
- **JumpIn時、操作入力で一時停止を解除**: 一時停止した状態から「自分で操作」に切り替えたとき、アクセル/ブースト入力をした瞬間に自動で一時停止解除するかどうかです。
- **HUDを表示**: 練習中に残り時間・選手名・状態などのHUDを表示するかどうかです。
- **画面にキー操作の説明を表示**: 練習中の画面左上に、キー操作の説明を表示するかどうかです。
- **ゴール演出(リプレイ・爆発)を無効化**: ゴール時のリプレイ演出・爆発エフェクトを無効化するかどうかです（実験的機能）。
- **再開時にボールを実物理へ解放(実験的)**: チェックした状態で一時停止から操作再開すると、その瞬間からボールが記録上の軌道を追うのをやめ、実際の物理演算に従うようになります。記録より遅いタイミングでボールに触れる練習をしたい場合などに使えます（直前の記録上の速度は引き継がれます）。この設定は、新しい練習を始めるたびにオフに戻ります。
- **キー割り当て**: 標準の割り当てを適用します。
- **言語・ウィンドウ**: 表示言語（日本語 / English）、ウィンドウの大きさ（右下のつまみのドラッグでも変更可）・不透明度を変更できます。日本語表示には Windows 標準フォント（BIZ UDゴシック）を使います。フォントや文字を追加した直後はゲームの再起動が必要です。日本語フォントが読み込めない環境では、自動的に英語表示になります。

### 安全機構

- 変換中は誤って別の変換を始められないようにボタンを無効化し、必要なら変換を安全に中断（キャンセル）できます。
- クリップが短すぎる場合はエラーメッセージを表示し、練習に適さない極端に短いクリップの作成を防ぎます。
- 保存ファイルの読み込み時にバージョン・内容の整合性をチェックし、壊れたファイルや別バージョンのファイルによる異常動作・クラッシュを防ぎます。
- フォルダ・クリップの名前変更や移動では、使えない文字の置き換えと、保存フォルダの外へ出るパスの拒否を行います。

## 現在対応していないこと・既知の制限

- HUDの日本語表示は一般的な文字に対応していますが、まれな漢字は表示されない場合があります。
- rumble・dropshotなど一部の特殊モード、制限時間付きモードには対応していません。
- 試合途中で離脱したプレイヤーがいるリプレイは、そのプレイヤーの動きが正しく再現されない場合があります。
- 元のリプレイ視聴中のネイティブな一時停止/再生をGUIから制御することは、BakkesMod側の制約により実装を断念しています（変換後の練習中の一時停止はキー操作で可能です）。
