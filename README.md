# ReplayClipTrainer

ReplayClipTrainer は、Rocket League のリプレイを「操作できる練習用プライベートマッチ」に変換する BakkesMod プラグインです。リプレイの好きな瞬間から、好きな選手（味方でも相手でも）の操作を奪って、同じシーンを何度も練習できます。

エアリアル練習、ドリブル練習、特定の場面での判断練習など、実際に起きたプレーをそのまま反復練習したい場合に使えます。

本プラグインは [JumpInReplay](https://github.com/Atomus48/JumpInReplay)（作者: Atomus48）をベースにしたフォークで、クリップ変換・保存管理・設定GUIなどを大きく拡張したものです。

## インストール方法

1. リポジトリの Releases（またはビルド済みzip）から `.dll` ファイルを取得します。
2. `.dll` ファイルを BakkesMod のプラグインフォルダにコピーします。
   - `C:\Users\<ユーザー名>\AppData\Roaming\bakkesmod\bakkesmod\plugins`
3. 設定ファイル（`plugins\settings` 内）も同様に対応するフォルダへコピーします。
4. 起動時に自動読み込みさせたい場合は、`cfg\plugins.cfg` の末尾に以下を追記します。
   ```
   plugin load replaycliptrainer
   ```
5. Rocket League を起動すれば使用できます。

## 使い方

BakkesMod の F2メニュー → Plugins → ReplayClipTrainer、またはコンソールで `togglemenu ReplayClipTrainer` を実行すると設定画面が開きます。基本的な操作はすべてこの画面から行います。

大まかな流れ：

1. 練習したいリプレイを再生する
2. リプレイをスクラブして、練習したい瞬間まで移動する
3. 「Convert Clip Around Current Position」でその場で練習開始、または「Save Clip to File」で後で使うために保存する
4. プライベートマッチが開始したら、好きな選手を選んで操作を奪う（JumpIn）

## 主な機能

### クリップの変換・保存

- **Replay Position**（リプレイ再生中のみ表示）: 現在の再生位置をスライダーで表示します。クリック/ドラッグで好きな位置に一発でジャンプできます。
- **Clip Conversion**:
  - 「Seconds Before Scrub Position」「Seconds After Scrub Position」: 現在のスクラブ位置の前後何秒を切り出すかを指定します。
  - 「Convert Clip Around Current Position」ボタン: 指定した範囲を切り出し、すぐにプライベートマッチとして練習を始めます。
- **Save Clip to File**: 名前を入力（空欄なら自動命名）してこのボタンを押すと、プライベートマッチを開かずにクリップをファイル（`.reclip`）として保存します。1本のリプレイから複数のシーンを保存し、後でまとめて練習することも可能です。

### 保存済みクリップの管理（Saved Clips）

- 保存済みクリップは一覧表示され、保存日時やプレイヤー人数が確認できます。
- フォルダに分けて整理できます（フォルダの作成・削除はエクスプローラー側で行い、プラグイン側では一覧をたどって閲覧・移動するだけのシンプルな作りです）。「Open Clips Folder」ボタンで、今見ているフォルダをそのままエクスプローラーで開けます。
- 「Refresh List」で一覧を更新、「Retry Last Clip」で直前に変換/読み込んだクリップをもう一度開けます。
- 各クリップには「Load」（読み込み）・「Delete」（削除、誤操作防止のため押すと「Confirm Delete」/「Cancel」に切り替わる2段階確認）があります。
- 古いバージョンで保存された互換性のないクリップは一覧でグレーアウトされ、誤って読み込まないようになっています。

### 練習中の操作

- 一時停止・巻き戻し/早送り、観戦する選手の切り替えができます。
- 「JumpIn」で、現在観戦している選手の操作を奪って自分でプレーできます。クリップを開いた直後は、元のリプレイであなたが実際に観戦していた選手が自動的に選ばれます。
- 練習中はHUD（残り時間・スコア・操作中の選手名など）を表示できます。

#### Bindings（キー割り当て）

設定画面の「Bindings」セクションにある「Apply Standard Bindings」ボタンを押すと、以下のキー/コントローラー割り当てが適用されます（初回に一度押せば、BakkesMod側に保存されるので次回起動時も押し直す必要はありません）。

| 操作 | キーボード | コントローラー |
| --- | --- | --- |
| 10秒早送り | → | DPad右 |
| 5秒巻き戻し | ← | DPad左 |
| 次の選手を観戦 | ↑ | DPad上 |
| 前の選手を観戦 | ↓ | DPad下 |
| 一時停止/再開 | B | 左スティック押し込み |
| JumpIn（操作を奪う/戻す） | V | Back/Selectボタン |

キー自体を変更したい場合は、BakkesMod本体の「Bindings」タブから個別に変更できます。

### 設定（Settings）

- **Conversion Resolution**: クリップ変換時に、元のリプレイを何倍速で読み込みながら記録するかの値です（0.1〜2.0、既定値0.5）。
  - `1.0` が等倍速。
  - `1.0`より小さい値（例: `0.5`）にすると、リプレイをゆっくり再生しながら記録するため、単位時間あたりに記録するデータの密度が上がり、変換後の動きがより滑らかになります。ただし変換にかかる時間は長くなります。
  - `1.0`より大きい値（例: `2.0`）にすると、リプレイを早送りしながら記録するため変換は速く終わりますが、記録のデータ密度が下がり、動きがやや粗く（カクつき気味に）なります。
  - 精度を優先したいときは小さい値、変換の速さを優先したいときは大きい値にしてください。
- **Limited Boost in Replay**: 練習中のブーストを制限あり/無制限のどちらにするかです。
- **Unpause on Controller Input When Jumping In**: JumpInで一時停止した状態から、アクセル/ブースト入力をした瞬間に自動で一時停止解除するかどうかです。
- **Show HUD in ReplayClipTrainer**: 練習中に残り時間・スコアなどのHUDを表示するかどうかです。
- **Disable Goal Replay/Explosion**: ゴール時のリプレイ演出・爆発エフェクトを無効化するかどうかです（実験的機能）。

### 安全機構

- 変換中は誤って別の変換を始められないようにボタンを無効化し、必要なら変換を安全に中断（Cancel）できます。
- クリップが短すぎる場合はエラーメッセージを表示し、練習に適さない極端に短いクリップの作成を防ぎます。
- 保存ファイルの読み込み時にバージョン・内容の整合性をチェックし、壊れたファイルや別バージョンのファイルによる異常動作・クラッシュを防ぎます。

## 現在対応していないこと・既知の制限

- 一部日本語表示でHUDの文字化けが残っています（BakkesMod側のフォント制約によるもの）。
- rumble・dropshotなど一部の特殊モード、制限時間付きモードには対応していません。
- 試合途中で離脱したプレイヤーがいるリプレイは、そのプレイヤーの動きが正しく再現されない場合があります。
- ネイティブのリプレイ一時停止/再生機能のGUI制御はBakkesMod側の制約により実装を断念しています。
